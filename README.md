# Ukelele-Quiz

An HTML5 application designed to help you quiz yourself on ukulele chords and improve your fretboard knowledge.

## Features
* **Fretboard Visualization:** Accurate alignment of standard ukulele frets.
* **Comprehensive Chords:** Tests knowledge across standard and flat chords.
* **Progress Tracking:** Instant feedback on chord recognition.
